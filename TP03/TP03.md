## Introduction to Hugging Face and Unsloth – Lesson Summary

In this lesson, the teacher introduced us to **Hugging Face** and **Unsloth**, two tools used in AI and LLM development.

We created a Hugging Face account and explored its main features, including Models, Spaces, and Documentation. 
We also covered several important concepts:
- Fine-Tuning: Adapting a pretrained model to a specific task using a smaller, task related dataset.
- Model Selection: Choosing a suitable LLM based on task requirements, model size, performance, computational resources, cost, and licensing.
- Model Loaders: Using the AutoModel family in Hugging Face Transformers to load pretrained models for different tasks, such as text generation, classification, and question answering.
- Unsloth: A tool that helps fine-tune LLMs more efficiently by reducing GPU memory usage and training time.

**Class Activities**: We created a Hugging Face account, explored its features, model selection, fine-tuning, and Unsloth. At the end of the lesson, the teacher assigned homework to review and summarize what we had learned.
